# 人像美颜与产品区区分指南

## 核心原则
客户诉求指向什么，就只审查什么。诉求为"产品问题"时，对与产品无关的内容（人像美颜、背景美化、滤镜、贴纸）进行的任何 AIGC 处理，均**不构成**欺诈证据，不作为风险升级依据。

## 区域划分方法
1. 商品区域：产品主体、产品破损/瑕疵细节、产品包装、与产品直接接触的部分。
2. 非商品区域：人物面部/身体、背景、水印贴纸、装饰元素。
3. 边界模糊时：以"客户索赔的是否为该区域的损坏"为准，不确定时保守归入非商品区域。

## 典型场景对照
- 客户发送"产品破损图 + 自己的美颜自拍"，只要产品区域真实 → 低危，按正常售后处理。
- 客户发送"产品破损图"，产品区域有生成痕迹 → 高危。
- 客户发送"使用效果对比图"，对比图中人物经过重度美颜，但诉求为"产品无效" → 美颜不计入；重点审查图文一致性与宣传承诺。

## 报告要求
出现"非商品区域存在 AIGC 但商品区域正常"时，报告须明确写明该结论及依据（低危判定原则），避免一线客服误读为欺诈。
